# QQ Music Daily 30 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a playable QQ Music Daily 30 card beside Guess You Like, with first-song artwork and a complete song-list detail view.

**Architecture:** Add an authenticated main-process Daily 30 service that returns normalized QQ songs over a dedicated IPC channel. Keep Daily 30 renderer state and playback independent from Guess You Like, then teach the existing song-list loader to resolve the Daily 30 temporary ID before the normal provider API.

**Tech Stack:** Electron IPC, TypeScript, Vue 3 Composition API, existing reactive stores, Node assertion tests, ESLint, webpack.

---
